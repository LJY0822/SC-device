# SC 游戏提示词与信息边界

运行时直接加载同目录的 game-prompts.json；该文件就是实际使用的系统提示词，修改后需更新 Service Worker 版本。没有另藏于游戏规则引擎的 LLM 提示词。

入口：SCGameHost.generate 使用 match；关键事件使用 event；结束使用 closing；统一后的海上对弈也使用 match / event / closing；保留的旧版手动入口使用 navalScene / navalEvent。每次调用的角色卡、公开输入和模板名称可在游戏“设置 → 提示词调用记录”中查看，不包含密钥。近期剧情仅取用户选择的角色会话最近十条文字，不写入 COMMS。

- 德州扑克：本地策略只收到指定座位自己的两张底牌与公开信息；LLM 一律只收公开投影，连用户自己的未摊牌底牌也不发送。牌库和完整存档不能进入提示词。模型不执行下注。
- 五子棋：棋盘为公开信息，落子由本地 Worker 搜索；模型只生成演出。
- Mastermind：求解 Worker 只收配置、历史猜测和反馈，绝不收 private.secret；普通提示词不含候选答案集合。只有正式结束后公开投影才包含答案。出题者也不需要知道秘密才能扮演。用户输入与密码一致的反馈后才推进。
- 黄金矿工：开局与结束可调用模型；运行中的得分事件只播放预设台词。返场最多一次简短演出，不在后台调用。难度和物理参数建议由程序限制范围，必须在预览中确认。
- 各游戏的赛后官方结果作为事实存档；自然语言评价单独展示，不参与规则判断。记忆只留游戏摘要与评价，按游戏和角色组合隔离，不自动写入聊天或其他角色会话。

文字请求沿用主聊天的角色独立 API 预设（无独立预设时使用全局配置）、模型、流式开关、温度和输出长度；使用主聊天相同的流式/普通响应解析器。开场等待不超过主聊天等待设置且最多 180 秒，事件最多 90 秒。错误会显示在开场状态或游戏提示区，并写入提示词调用记录。

近期剧情按 createdAt 排序保留最近十条文字，角色选择时会预选当前/最近会话，可显式改为“不读取聊天情境”。event / closing 的输入固定包含已确认的 state.scene 和本局选择的 recent，不读取其他会话。

开场允许编辑标题、场景和贴纸，慢响应不会覆盖等待期间手动改过的文字与矿工参数。确认后冻结场景，新响应不会改变进行中的对局。

所有请求有超时、AbortSignal 和 Match ID 检查。新局、退出或切到后台会取消等待中的请求，迟到结果不会写入新局。无文字 API 时仍可本地完整游玩。


场景插画的生成提示词单独保存在 ../assets/game-stickers/PROMPTS.md。插画由内置生图工具离线生成；游戏运行时不会调用生图接口。
